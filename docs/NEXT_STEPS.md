# 当前交付与后续验证

2026-09-07：五批实施已落地到工作区，存档结构版本 7，仍使用 `/api/v2`。入口、默认规则、迁移恢复与接口见[五批交付说明](FIVE_BATCH_EXPERIENCE.md)，实测结果见[验收报告](../reports/acceptance/FIVE_BATCH_ACCEPTANCE.md)。

后续应扩大实际样本覆盖：

1. 中文改述、同名人物、远距离承诺和隐含伏笔的召回。目前采用实体、事项和中文词项检索，没有引入向量服务。
2. 更多真实普通行动的完整／合并审查对照。固定确定性负载的请求数下降不能外推为真实模型整体延迟承诺。
3. 四类规则的登记模板及故事内容。通用规则、初始障碍、物品与交易奖励入口已经具备，尚不是完整题材数值系统。
4. 分析正文降级原因，提高陈述与段落绑定的模型遵循率，保留校验后发布和简述。
5. 扩大真实路线选择、多个 NPC 竞争触发和复杂传话链的长期样本。

这些是覆盖范围的扩展，不改变单场选择、手动恢复托管、阶段超时暂停及正文重试规则。
